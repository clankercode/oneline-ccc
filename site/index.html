Your coding client.
Your model gateway.

Point Codex at your proxy with one PowerShell command. Bring a URL and an API key; choose your model and context budget.

Paste into PowerShell
& ([scriptblock]::Create((Invoke-RestMethod 'https://clankercode.github.io/oneline-ccc/setup-codex.ps1')))

Runs the standalone installer as your user. Windows PowerShell 5.1 or PowerShell 7. Your gateway must support the Responses API.

A few choices. Then start coding.

  1. Connect your gateway

    Enter your base URL, including /v1 if needed, and your API key at a private prompt. No deployment URL or key is bundled in this project.

  2. Choose a model and a budget

    Select gpt-6.1-sol, glm-5.3, glm-5.3-flash, or a custom ID. Enter a context budget, such as 272000, 353000, or 500000 tokens, within your model’s capacity. Compaction starts at 90% by default.

  3. Launch Codex

    Run codex: LLMP is your default upstream. Setup installs Codex if needed and preserves unrelated configuration settings. You can then opt into Windows SSH server setup.

Your default configuration

Setup updates config.toml under your Codex home and keeps an optional llmp.config.toml named profile. Changed files get backups; unrelated main settings are preserved.

The key goes into your Windows user environment, not TOML. This is persistent environment storage, not an encrypted vault. Reopen other terminals to inherit it.

If Node.js is missing, setup offers a winget LTS installation, which may request administrator approval.

Explicit model controls

Optional discovery lists model IDs. The LLMP Sol preset supplies Fast and Ultrafast controls, including /ultrafast, through a complete catalog matching your Codex version. Other models can use a gateway catalog or explicit tier settings.

Rerunning setup offers your existing LLMP values as defaults. Press Enter to keep them and reuse a saved API key without displaying it.

A context setting cannot expand a model’s capacity. The selected budget applies to this profile, including when you switch models within it.

Read the usage and advanced options before adding catalogs or tiers.

Optional SSH access to the Windows box

Setup can install OpenSSH server, configure its service and firewall, and authorize a pasted public key or keys from a GitHub username. It defaults to the local subnet on the Private network profile. Public-profile access needs a separate opt-in. Administrator approval is required; your network classification is never changed automatically. SSH setup details.
